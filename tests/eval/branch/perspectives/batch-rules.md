# プロジェクト固有の設計観点

このプロジェクトの定期ジョブ・バッチに固有の規約。標準の観点に加えて確認する。

## 定期ジョブの登録

- 新しい定期ジョブ (cron・スケジューラ) は、リポジトリの `ops/jobs.yaml` に登録する。登録には、所有チーム、止め方 (無効化の手順)、失敗したときの連絡先を書く。設計書にこの登録が無い定期ジョブは差し戻す

## 時刻

- 時刻と日付の境界は UTC で決めて保存する。JST に変換するのは画面・グラフ・通知に表示するときだけ

## 再実行

- 集計バッチは、同じ期間をもう一度実行しても結果が変わらないようにする (二重に計上しない)。再実行の手順を設計書に書く
