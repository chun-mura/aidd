# CI ビルド時間の週次集計バッチ 設計書

規模: 社内バッチ1本の追加のため要約形式

## 背景と目的

CI のビルドが遅くなった時期を後から追えない。CI のジョブごとの所要時間を毎週集計し、週ごとの推移をグラフにして開発チームの週次の振り返りで見る。

## スコープ / やらないこと

- やる: 前週分のジョブの所要時間を集計して CSV に追記し、推移のグラフ (PNG) を作る
- やらない: ジョブの失敗の原因分析、通知、CI の設定の変更

## 構成と責務

| コンポーネント | 責務 |
|---|---|
| `ArtifactScanner` | 社内の CI ランナーが共有ディレクトリ `/srv/ci-artifacts/` に書くジョブごとの JSON (ジョブ名、開始時刻、終了時刻、成否) を読む |
| `DurationAggregator` | ジョブ名ごとに前週の所要時間の中央値と 90 パーセンタイルを出す |
| `CsvAppender` | 集計結果を `/srv/ci-stats/weekly.csv` の末尾に追記する。列は `week_start, job_name, p50_sec, p90_sec, runs` |
| `ChartRenderer` | `weekly.csv` 全体から、ジョブごとの推移のグラフを `/srv/ci-stats/weekly.png` に書く |

## 実行

- 集計用のホストの cron で毎週月曜 06:00 に起動する。対象は前週の月曜 00:00 から日曜 23:59 まで
- 週の境界と `week_start` は、ホストの時刻 (JST) で決めて書く
- 失敗して手で再実行するときは、同じコマンドをもう一度実行する

## データ

- 扱うのはジョブ名・時刻・所要時間・成否だけで、個人や顧客の情報、認証情報は含まない
- 共有ディレクトリの JSON は CI 側が 30 日で消す。CSV と PNG は消さない

## エラー処理

- 形式が壊れた JSON は飛ばし、件数を標準エラーに出す
- 前週の JSON が1件も無ければ、何も追記せずに終了コード 0 で終わる

## 運用

- デプロイ: スクリプトと cron の設定を集計用のホストに置く。ロールバックは cron の設定の削除
- 監視: 無し (週次の振り返りでグラフが更新されていなければ気づく)
