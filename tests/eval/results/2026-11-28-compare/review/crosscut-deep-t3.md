## 経路

- **深さ**: `--depth=deep`。`--security` と `--verify-sources` は付けていない。
- **小規模対象ショートカット**: 使っていない。対象は1ファイル・386行で100行を超えており、指示でも使用を禁じられている。
- **事前判定**
  - `.aidd/review-dismissed.md` と `.aidd/design-perspectives.md` は無い。このため棄却済み一覧は「なし」とし、Agent 4（プロジェクト固有観点）は起動していない。
  - `/aidd:issue-split` は提案していない。新サービス・注文サービス・会員サービスの改修と、移行・カットオーバーは同じメンテナンス枠で行う一体の横断的変更で、それぞれ単独ではマージできない。このため分割できないと判断し、レビューを続けた。
  - Agent 5（source-verifier）は `--verify-sources` が無いため起動していない。
- **並列 dispatch（1メッセージで4つ）**
  - aidd:reviewer: Agent 1（構造）
  - aidd:reviewer: Agent 2（データとエラー）
  - aidd:reviewer: Agent 3（実用性）
  - aidd:security-reviewer: Agent 6（起動理由は最終節に記載）
  - 各 agent には対象パス・担当観点・棄却済み一覧「なし」だけを渡し、「このファイルだけをレビューする」と明示した。
- **refuter（aidd:refuter, sonnet）**: 起動した。reviewer から high/mid が出たため。重複をまとめた F1〜F22 の22件を渡した。
- **arbiter（aidd:design-arbiter）**: 起動した。deep の規則では、反証後に high/mid が残れば起動する。今回は22件すべてが残り、F2・F5・F13 の深刻度と F4 の代案で reviewer 間の食い違いもあった。
