## 記録のブロックの不具合 (試行1)

試行1では、実行担当が reviewer・source-verifier をバックグラウンドの agent として dispatch し、その tool result は起動の通知だけだった。初版の `# eval branch tools:` は tool result を返答とみなしていたため、試行1の `tools.md` の「source-verifier の返答」には起動の通知が入り、返答そのものが無い (`sources-t1/sources-t1.tools.md`。凍結したので直していない。通知には一時ディレクトリの絶対パスが残っている)。返答は agent の `SubagentHandback` に入るので、ブロックを直し (`3ce5ced`、rebase の後は `2ef11ac`)、照合済みの試行1の stream-json (`local.sha256` で照合) から直したブロックで作り直した記録を `regrade-t1/` に置いた。試行1の外部情報の判定は `regrade-t1/sources-t1.tools.md` で採点した (最終回答の `## source-verifier の判定` とも一致)。起動の判定 (dispatch の数) は初版と直した版で同じだった。
